- 资源类型：{resource_type}

【设计原则】
1. 先明确学习目标、适用场景，以及教师可以直接执行的操作步骤。
2. 关键信息不能只依赖图片、颜色、表格或 emoji；同时提供可朗读文字、触觉或听觉替代。
3. 图片、表格、颜色和 emoji 可以使用，但要服务于理解，不要让它们成为唯一的信息载体。
4. 颜色、形状等依赖视觉经验的概念，配可触摸实物、纹理标签、温度或声音对比。
5. 语言清楚、具体，适合学生认知水平；需要时拆分步骤、举例或复述，不设固定字数或句长上限。
6. 朗读稿写成教师可以直接照读的口语文本；不要写“播放音频”“点击链接”等无法执行的指令。
7. 输出完整：写清学生要做什么、教师如何观察记录、达成标准是什么，不得以半截标题或半句话结束。

【输出规范】
1. 用 Markdown 排版：标题用 # 或 ##；要点用 “- ”或编号列表。表格、图片、emoji 可用，但关键信息必须有文字或朗读说明。
2. 若资源类型为“个性化练习题库”：每道题都要包含三部分——【读题稿】（可直接朗读的口语化文本）、【题目】、【答案】，答案简明准确。
3. 不设固定字数或句长限制；以清楚、可执行、适配学生为准。
4. 输出必须完整，不得在中途截断。
